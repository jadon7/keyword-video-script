# 关键词科普视频脚本

将一个或一批关键词转成科普短视频的调研资料、开头方案和口播稿。项目以 Codex 技能文件组织，由智能体按规则执行。

默认面向没有相关知识的普通观众，平台为抖音，时长为 2—3 分钟。用户可以指定其他平台、时长、受众和切入点。

## 工作流程

1. **调研**：通过 OpenCLI 查找抖音、小红书、B 站、公众号和 Twitter/X 的相关内容，用原始论文、机构资料等核查关键事实。记录来源、可见互动数据、观众问题和资料缺口。
2. **提案**：每个关键词提供 10 个不同方向的开头，附故事主线、证据链接和推荐理由。默认等待用户选择后再写全文。
3. **写稿**：沿选定开头展开故事，解释概念、研究和生活案例。口播正文一句话一行，只包含可直接朗读的内容。
4. **交付**：用飞书 CLI 分别创建调研文档和口播稿，回读确认内容、顺序、换行和版本，再交付链接。

批量任务使用索引表记录各选题的阶段、开头选择、稿件版本和文档链接。已选定的选题可先写稿，其他选题保留在提案阶段。

## 文件结构

```text
keyword-video-script/
├── SKILL.md               # 入口：输入、调研、提案、写稿和交付流程
├── agents/openai.yaml     # Codex 显示名称、简介和默认提示词
├── references/writing.md  # 口播语言、证据、节奏、结尾和排版规范
└── README.md              # 项目说明和使用示例
```

## 使用准备

- 将本目录放在 Codex 的技能目录中，例如 `~/.codex/skills/keyword-video-script/`。
- 准备 OpenCLI 及所需平台的访问权限；执行前查看当前命令帮助。
- 准备飞书 CLI、用户身份授权及 `lark-doc` 技能，用于文档创建和编辑。
- 需要转写音视频时，默认使用 `whisper --model base`。

访问受阻时，记录缺失资料并继续可完成的部分。飞书不可用时保留本地稿件，并说明尚未完成文档交付。

## 使用示例

单个选题：

```text
使用 $keyword-video-script 调研“认知失调”。
先给我调研文档和 10 个开头方案，等我选定后写口播稿。
```

批量选题：

```text
使用 $keyword-video-script 处理以下关键词：
安慰剂效应、幸存者偏差、熵增。
面向普通观众，每篇 2—3 分钟。
先完成整批调研和开头方案，并建立飞书索引。
```

选择方案后：

```text
认知失调用方案 03。保留这个开头，完成口播稿，
正文一句话一行，单独写入飞书文档，标题标记 v1。
```

## 内容规则与范围

- 区分真实事件、研究结论、作者观点和假设场景。关键事实保留可追溯来源。
- 用可见数据说明传播表现；缺失数据不记为零，不跨平台直接比较热度。
- 调研报告保留来源和分析，口播正文不混入镜头、配乐、时间码或写作说明。
- 大改保留旧稿并增加版本号；局部修改沿用当前文档。
- 已合并适用于科普的写作规范，无需额外安装 `scriptwriter`。
- 分镜、配音、素材制作和剪辑按用户另行要求执行。

当前仓库包含技能定义、写作规范和界面配置，不包含已完成的选题资料或视频成品。
